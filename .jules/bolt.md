## 2024-05-16 - SPA Anchor Links & Code Splitting
**Learning:** This application relies on native HTML anchor links (e.g., `href="#services"`) for navigation. Using `IntersectionObserver` to defer rendering of off-screen components removes their target IDs from the initial DOM, breaking direct navigation on initial load. Furthermore, simply using `React.lazy()` also removes the target IDs during the initial load because the `Suspense` boundary renders its fallback first.
**Action:** When using `React.lazy()` for code-splitting components that serve as anchor targets, the `id` attributes must be placed on a wrapper `div` *outside* the `<Suspense>` boundary. This ensures the targets are immediately present in the DOM for direct navigation, while the actual components load asynchronously.
