## 2024-05-24 - Accessible Mobile Navigation Patterns
**Learning:** When building responsive mobile menus in React with icon-only buttons (like Lucide React icons), ARIA attributes (`aria-expanded`, `aria-controls`, `aria-label`) are crucial, but equally important is explicitly adding visible focus states (e.g., `focus-visible:ring-2`) because default browser focus rings are often stripped or invisible against dark mode backgrounds. Furthermore, decorative SVGs must be explicitly hidden from screen readers using `aria-hidden="true"` to prevent redundant/confusing announcements.
**Action:** Always test mobile menu buttons with both keyboard navigation (ensuring visible focus against the active theme) and screen readers, explicitly linking the trigger to the menu container via `id` and `aria-controls`.
