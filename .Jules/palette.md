## 2024-05-15 - Mobile Menu Toggle Accessibility
**Learning:** Icon-only buttons used for mobile navigation frequently lack accessible names and explicit screen-reader state synchronization (`aria-expanded`, `aria-controls`), making them completely invisible or confusing to non-sighted users. Additionally, common utility class resets (`focus:outline-none`) entirely remove keyboard focus visibility unless explicitly replaced with an alternative (like `focus-visible:ring-2`).
**Action:** When implementing or reviewing icon-only interactive elements (especially disclosure widgets like menus), ensure they have a descriptive `aria-label`, explicitly synchronize their open/closed state with `aria-expanded`, map them to the content they reveal via `aria-controls`, explicitly hide the decorative SVGs from screen readers using `aria-hidden`, and most importantly, provide a clear, visible focus indicator (e.g., `focus-visible:ring-moss-500`) for keyboard navigation.
